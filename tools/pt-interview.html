HOW TO

사용 방법 4단계

처음 한 번만 해보면 이후에는 주제만 바꿔 계속 연습할 수 있습니다.

1

프롬프트 붙여넣기

복사한 프롬프트를 쓰는 AI 새 채팅에 붙여넣고 전송합니다.

2

정보·유형·시간 설정

AI가 물어보면 기업·직무·전공·계열·산업을 답하고, 유형 1개와 작성 제한 시간·발표 시간을 직접 정합니다.

3

HTML 파일 저장

AI가 출력한 코드를 복사해 PT면접_시험지.html로 저장하고 크롬으로 엽니다. 미리보기가 되는 AI라면 그대로 써도 됩니다.

4

시험지로 연습

답안을 쓰고 제출하면 모범답안이 열립니다. 대안 주제는 “대안 주제도 알려줘”라고 말하세요.

WHAT YOU GET

만들어지는 시험지의 6가지 기능

한 파일 안에서 문제 풀이부터 발표 연습까지 이어집니다.

1시험지

상황·과제·자료·기출 근거가 시험지처럼 정리됩니다. 내가 정한 작성 제한 시간 타이머가 함께 제공됩니다.

2내 답안 작성

발표 시나리오의 본론과 같은 3묶음(문제점 및 현황 분석 / 해결방안을 PREP로 / 기대효과와 남아있는 문제점)에 먼저 써봅니다. 문제풀이형은 해결방안 묶음에 ‘풀이 과정과 답’ 칸이 추가됩니다. 자동 저장됩니다.

3모범답안 비교

내 답과 AI 답을 PREP별로 나란히 보고, 자료 활용 여부와 자기 진단 점수를 확인합니다.

4답변 방향

본론 1·2·3 순서로 칸마다 말하기 틀과 쓸 자료, 자주 하는 실수를 알려줍니다. 해결방안은 PREP 순서로 안내합니다.

5발표 시나리오

오프닝부터 마무리까지 구어체 대본. 스토리텔링과 자문자답이 들어가고, 내가 정한 발표 시간에 맞춘 분량과 발표 타이머가 제공됩니다.

6논리 흐름 점검

문제 현황 → 해결방안 → 기대효과 → 남은 문제점 순서, 구간 연결, 발표 시간 적합성을 10가지 항목으로 자동 점검합니다.

FAQ
자주 묻는 질문
막혔을 때 확인해 보세요.

    
AI가 코드만 길게 보여주고 화면이 안 떠요
  • 코드 블록의 복사 버튼으로 전체를 복사해 메모장에 붙여넣고, 파일 이름을 PT면접_시험지.html로 저장하세요(파일 형식은 ‘모든 파일’).
  • 저장한 파일을 더블클릭해 크롬으로 열면 됩니다.

    
중간에 코드가 끊기거나 화면이 깨져요
AI에게 “끊긴 부분부터 이어서 전체 HTML을 처음부터 다시 출력해줘”라고 요청하세요. 그래도 안 되면 “DATA 구간(JSON)만 다시 출력해줘”라고 하고, 앞의 정상 파일의 DATA 구간만 바꿔 끼우면 됩니다.

    
자료의 숫자와 기사는 믿어도 되나요?
각 자료에 출처 확인 / 가상 자료 / 확인 필요 / 개념 정리 표시가 붙습니다. 가상 자료와 확인 필요 표시는 연습용이므로, 실제 면접 전에는 반드시 직접 출처를 확인하세요.
검색 기능이 없는 AI는 자료가 대부분 ‘가상 자료’로 표시됩니다. 검색이 되는 모드(웹 검색)를 켜면 출처 있는 자료가 늘어납니다.

    
다른 주제로 또 연습하고 싶어요
같은 채팅에서 “대안 주제도 알려줘”라고 입력하면 같은 유형의 새 시험지를 다시 만들어줍니다. 유형을 바꾸려면 “상황형으로 다시 만들어줘”처럼 말하세요.

    
내 답안은 어디에 저장되나요?
같은 컴퓨터, 같은 브라우저에만 저장됩니다. 파일을 다른 곳으로 옮기거나 브라우저 기록을 지우면 사라질 수 있으니, 중요한 답안은 따로 복사해 두세요. 상단 ‘PDF 저장’ 버튼으로 결과를 PDF로 남길 수도 있습니다.
