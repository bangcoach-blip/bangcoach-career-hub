# 자소서 작성 도구 설계 (`tools/cover-letter.html`)

## 목적
경험 정리 결과가 자소서 작성으로 바로 이어지게 해, 갤러리 사용자가 복사·재입력 없이 항목별 자소서를 완성하도록 한다.

## 목표
- SPARK 경험 지도에서 버튼 한 번으로 새 창의 자소서 도구가 열리고 항목과 1차 초안이 채워진다.
- 왼쪽에 항목, 오른쪽에 ① 경험 정리 1차 초안과 ② 방코치 피드백 반영본을 보여준다.
- 기본 항목과 기업별 항목을 도구 안에서 추가·삭제한다.
- 기업·직무·산업 분석 자료를 업로드해 요청에 반영한다.

## 하지 않는 것
- API 연결, 서버 저장, 로그인.
- 메뉴 재편(자기소개서/면접 + 흐름도). 이 도구 다음의 별도 작업이다.

## 실패로 보는 상태
- 사용자가 작성한 ② 글이 다시 넘겨받기나 결과 붙여넣기로 사라지는 것.
- 근거 없는 경험·수치가 표시 없이 ②에 들어가는 것.

## 제약
- 정적 사이트(Vercel). 단일 HTML 파일, 기존 `tools/self-intro.html`의 화면 방식·저장 방식(localStorage, 실패 시 메모리)을 따른다.
- 글 문체와 항목별 작성 기준은 `data/prompts_youth.csv`의 자기소개서 프롬프트를 바탕으로 한다.

## 검토한 방식
| 방식 | 장점 | 단점 |
|---|---|---|
| ① 별도 도구 (**선택**) | 기존 도구와 같은 구조, 새 창 흐름에 맞음 | 데이터 연결을 따로 만들어야 함 |
| ② 경험 지도 안에 추가 | 연결이 쉬움 | 큰 파일이 더 복잡해짐 |
| ③ 갤러리 메인에 추가 | 한 사이트 느낌 | 2단 화면이 좁고 메인이 무거워짐 |

AI 왕복은 "전체 한 번에"(사용자 선택). 항목별 왕복, 혼합 방식은 제외.

## 화면
```
상단: 지원 기업 · 직무 | 자료 업로드 | [전체 요청문 복사] [결과 붙여넣기] [내려받기]
┌ 항목 목록 ─────┬ 선택한 항목: 문항 원문 · 글자 수 ─────────────┐
│ 기본 항목       │ ① 1차 초안(경험 정리) │ ② 방코치 피드백 반영본 │
│ 기업별 항목     │   읽기 전용           │ 수정 가능, 글자 수     │
│ [+ 항목 추가]   │ 사용한 경험           │ 피드백 설명            │
└───────────────┴──────────────────────────────────┘
```
좁은 화면에서는 위아래로 쌓는다.

## 흐름
1. `spark-map.html` 결과의 [자기소개서 작성하기]가 수정 반영된 데이터를 전용 localStorage 키에 저장하고 `tools/cover-letter.html`을 새 창으로 연다.
2. 도구는 `items`를 항목으로 만든다. ①은 해당 항목의 예시 글(`drafts`)을 쓰고, 없으면 1순위 경험의 SPARK 내용을 정리해 보여준다.
3. 자동 연결이 안 되는 경우(다른 주소, 내려받은 파일)를 위해 [경험 데이터 붙여넣기/파일 불러오기]를 둔다. 경험 지도 없이 빈 상태로 직접 작성도 가능하다.
4. [전체 요청문 복사]: 작성 기준, 항목(문항·글자 수), ① 초안과 경험, 업로드 자료를 하나로 합친다. 사용자가 AI에 붙여넣는다.
5. [결과 붙여넣기]: AI의 JSON을 읽어 항목별 ② 본문과 피드백에 배분한다. 중간에 잘린 응답은 완성된 항목만 반영하고, [남은 항목 이어서 요청]을 제공한다.

## 규칙
- 다시 넘겨받으면 ①만 갱신한다. ②와 직접 추가한 항목은 유지한다.
- 이미 ②가 있는 항목에 새 결과를 넣으면 이전 글을 한 단계 되돌릴 수 있게 보관한다.
- 요청문은 경험에 없는 사실·수치를 만들지 말고 `[확인 필요]`로 표시하게 한다.
- 업로드 자료: PDF, DOCX, TXT/MD를 브라우저에서 글자로 읽는다. 글자가 없는 PDF나 너무 긴 자료는 AI에 직접 첨부하라고 안내하고, 요청문에도 "첨부 자료 참고"를 넣는다. 자료는 종류(기업/직무/산업)를 지정하고 삭제할 수 있다.
- 저장 용량 초과 시 알리고 작성 글 저장을 우선한다.

## 만드는 사람 재량
- 기본 항목 목록(CSV의 자소서 항목에서 구성), 글자 수 기본값, 요청문 분량 상한.
- 내려받기 형식(기존 도구의 방식 재사용), 파일 읽기 라이브러리(CDN, 버전 고정).

## 확인 방법
로컬 미리보기에서 예시 데이터로 넘겨받기 → 항목 추가 → 자료 업로드 → 요청문 복사 → 정상·잘린 결과 붙여넣기 → 새로고침 후 유지 → 좁은 화면을 확인한다.
